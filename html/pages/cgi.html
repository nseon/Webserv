Démonstrations CGI ⚙️

Webserv exécute des scripts CGI/1.1 (Python et Perl) et renvoie leur sortie. Chaque démo ci-dessous appelle un script via GET ou POST.

Variables d'environnement GET

Le script env.py affiche les variables CGI que le serveur lui transmet (méthode, query string, ports, adresse cliente…).

Salutation dynamique GET

greet.py lit la QUERY_STRING et génère une page personnalisée. Les champs sont envoyés dans l'URL (GET).

Calculatrice POST

calc.py lit le corps de la requête POST sur son stdin (selon CONTENT_LENGTH) et calcule le résultat côté serveur.

Formulaire de contact POST

form.py reçoit les champs du formulaire en POST et renvoie un récapitulatif.

Analyse de texte POST Perl

Démo dans un autre langage : le script Perl analyze.pl reçoit un texte en POST et renvoie le nombre de caractères, mots et lignes.

Gestion d'erreur CGI 502

Le script crash.py contient une erreur de syntaxe volontaire : l'interpréteur Python échoue et ne produit aucune sortie CGI valide. Webserv doit alors répondre 502 Bad Gateway au lieu de planter.

Timeout CGI 504

Le script timeout.py dort indéfiniment sans jamais répondre. Webserv doit détecter l'absence de réponse, tuer le processus CGI et renvoyer une erreur (504 Gateway Timeout) au lieu d'attendre éternellement. (la requête peut donc rester en attente quelques secondes avant l'erreur)
